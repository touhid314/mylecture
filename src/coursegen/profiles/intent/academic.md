# Intent profile - academic

learning intent: master material as a serious student in a course or degree path, not primarily to cram for one assessment.

planning guidance:
- prioritize syllabus coherence, prerequisite chains, definitions, disciplinary conventions, and conceptual depth
- build each lecture toward the next unit skill; name what learners should carry forward
- use interactives for problem-set-style reasoning, model inspection, argument comparison, or multi-step analysis
- prefer depth and understanding over trap-hunting or timed drill; reserve exam-style pressure for the `exam` intent
- use games sparingly; only when repeated practice clearly supports coursework fluency
