# Course profile - undergraduate

audience: university undergraduates. Assume introductory coursework in the field, but do not assume specialist depth beyond the requested level.

visual system:
- aspect ratio 16:9, dark technical theme (#121212)
- precise topic-native visuals: structured examples, systems, evidence, workflows, formal representations, case comparisons, or stepwise reasoning
- use correct notation, terminology, and conventions for the subject when needed
- labels 22px+; align elements on a grid; no decorative clutter

teaching style:
- open with the problem, question, or use case that motivates the concept
- state definitions, then work a representative example
- call out assumptions and edge cases
- connect ideas to applications or assessment-style reasoning when appropriate
- pace: 4-6 minute lectures

pacing:
- about 150 words narration per minute
- use standard terminology without over-explaining basics
