# Course profile - elementary (grades 3-5)

audience: elementary learners (grades 3-5). Use concrete, familiar analogies drawn from the requested topic. Avoid unexplained abstract vocabulary.

visual system:
- aspect ratio 16:9, dark charcoal background (#121212)
- large readable labels (28px+), generous padding, no overlapping text
- simple flat illustrations that represent the topic directly; avoid subject-specific stock motifs unless the prompt calls for them
- one hero visual per scene; evolve it incrementally across sentences
- animations: gentle highlighting, revealing, sorting, moving, or counting when useful - never chaotic motion

teaching style:
- begin with a familiar situation or question, then quickly name the skill for the lesson
- step by step with an example every 1-2 sentences
- define terms in plain English before using them
- pace: slow; 2-4 minute lectures
- end each lecture with one clear "you can now..." takeaway

pacing:
- about 120 words narration per minute (slower than default)
- prefer short sentences in narration
