# Course profile - middle school (grades 6-8)

audience: middle school learners. Connect concrete examples to more precise ideas, and define new vocabulary before expecting fluent use.

visual system:
- aspect ratio 16:9, dark theme (#121212)
- clean topic-native visuals: labeled steps, comparisons, timelines, models, tables, maps, examples, or systems when useful
- readable sans-serif labels (24px+), consistent spacing
- evolve one visual model across related sentences; change scene only when the subtopic shifts

teaching style:
- begin with a relatable problem or question, then connect it to the lesson goal
- introduce vocabulary with a quick example
- show common mistakes and how to avoid them
- pace: 3-5 minute lectures

pacing:
- about 135 words narration per minute
- mix everyday context with correct terminology
