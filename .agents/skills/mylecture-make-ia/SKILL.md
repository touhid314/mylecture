# Task
Make an interactive session using frontend web technology to teach all the topics in the reference material.

# Workflow
- You must follow this contract: `.agents\mylecture-contracts\html-input-contract.md`

example: `templates\minimal-interactive\interactive.html`

- You MUST only have one kind of segment: interactive. 

- Keep Next/Previous button for users to step through the interactive demo.

- In case user has to click or interact in a certain way, keep  clear guideline on how to interact.

# Theme
Full screen.
background color: complete black.
font family: Arial
* You can use other fonts if appropriate in certain case.

Use large font so that things are easy to see.
Minimum font size = 25px.

# Deliverables
Default deliverables folder: folder of the reference material
1. `interactive.html`
