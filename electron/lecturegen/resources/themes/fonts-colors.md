# Theme

## Background
Solid dark charcoal `#121212`. No grid.

## Font
Family: Lato only.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Lato:ital,wght@0,400;0,700;1,400;1,700&display=swap" rel="stylesheet">
```

```css
font-family: 'Lato', sans-serif;
```

## Type size
- Readable text (titles, teaching copy, labels, table cells, callouts): at least `18px`.
- Tick marks and other non-reading helper marks: `12px`–`14px`.
- Nothing the viewer is meant to read may go below `18px`.

## Colors
- Background: `#121212`
- Primary text and strokes: `#f5f5f5`
- Secondary text and labels: `#a3a3a3`
- Accent / key terms: `#7dd3fc`
- Cards and panels: `#1e1e1e`
- Borders: `#3f3f46`
