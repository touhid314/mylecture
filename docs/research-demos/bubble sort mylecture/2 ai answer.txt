### Understanding Bubble Sort

Bubble Sort is one of the most fundamental and intuitive sorting algorithms in computer science. While it is rarely used in production environments due to its inefficiency with large datasets, it serves as an excellent introductory tool for understanding algorithmic logic, array manipulation, and the concept of time complexity.

The algorithm gets its name from the way larger elements "bubble" up to the top (or end) of the list, much like air bubbles rising to the surface of water. It is a comparison-based algorithm that operates by repeatedly stepping through the list to be sorted.

Here is how the core mechanism works:
1. **Initialization:** The algorithm starts at the very beginning of the data array.
2. **Comparison:** It compares the first two adjacent elements.
3. **Swapping:** If the first element is strictly greater than the second (assuming an ascending sort), the algorithm swaps them. If not, they remain in their current positions.
4. **Iteration:** The algorithm moves one step forward to the next adjacent pair (the second and third elements) and repeats the comparison and potential swap. This step-by-step evaluation continues until the end of the array is reached.

At the conclusion of this first complete "pass," the largest element in the entire array is guaranteed to have bubbled its way to the very last position. Because this final position is now correctly sorted, the algorithm ignores it in subsequent passes. The process repeats from the beginning, comparing and swapping the remaining unsorted elements. The algorithm safely terminates when it completes a full pass without needing to make any swaps, indicating that the entire list is fully sorted.

In terms of performance, Bubble Sort has a worst-case and average-case time complexity of $O(n^2)$, where $n$ represents the total number of items being sorted. This quadratic growth means the time required to sort increases drastically as the dataset grows. However, it boasts a best-case complexity of $O(n)$ if the list is already perfectly sorted, provided the implementation includes an early-exit flag. Its space complexity is a highly efficient $O(1)$, as it requires only a single temporary variable to facilitate the swapping process, sorting the data entirely in-place.
