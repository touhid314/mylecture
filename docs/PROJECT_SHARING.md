# Share an editable project

Available in MyLecture 1.2.0.

In **Create → Projects**, hover over a project and click **Export project** (the download icon). Save the `.lecture` file and share it.

On the other computer, choose **Create → Projects → Import** and select that file. It opens as a new project, ready to play and edit. Importing never replaces an existing project.

The package includes the project's source files, local assets and attachments, conversation, narration edits, and recorded narration audio. It does not include app settings, connected accounts, installed AI engines, or voice models. The recipient uses their own app configuration when generating new content.

Packages can be up to 1 GB, with up to 2 GB of expanded project files. Linked files must first be copied into the project folder.
