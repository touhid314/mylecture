\# Teaching style

This is a x (stickman pointing  to left), This is a y (stickman pointing to right), what's the difference?

Then you explain the difference in 2-3 sentences.



\## very important

while saying 'this is a x' the stickman must be pointing to the left.

Then immediately when saying 'this is a y' the stickman must be pointing to the right.
