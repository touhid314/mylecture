# Additional instruction
- Keep the question on the very top throughout the explanation. Make sure it doesn't eat up too much space of the screen.
- Write math equations progressively from left to right as if written by hand with a pen. Do NOT reveal entire math equations instantly in one block.
- Think of yourself like a teacher solving a problem in front of a student, making sure the student can see and understand every step nicely.
- Write like someone is solving a math on paper, line by line. 
- Try to keep math steps on the same screen, not screen switching for every math line. Only switch to new screen if topic change or a screen fills out.
- Keep all math equation inside an html div, to make sure multiple equations don't overlap to maintain equation lines properly.
- use => between consecutive math lines coming from one another.
