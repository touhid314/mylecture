# Theme
# Style: Minimalist Technical Motion Graphic

Background: Solid, dark charcoal matte (#121212). No grid.



# Typography, Fonts \& Imports:

- CSS Font Import: @import url('https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;700\&display=swap');

- Font Family: 'JetBrains Mono', 'Fira Code', monospace;

- Font Sizes: Main Titles must be 40px (bold, uppercase, letter-spacing: 0.12em); Card Headers must be 32px; and all Body Data/Code text must be 26px.

- Spacing Rule: Set line-height: 1.6 and add substantial padding/margins between all text blocks to absolutely guarantee no overlapping text.

# Shapes & Geometry:

- Borders: Ultra-thin (1px), crisp solid vector wireframes only. No shadows.

- Graphics: Clean, flat 2D geometric shapes and smooth mathematical bezier curves.

-  Don't use borders to set out content area box, it's unprofessional.



# Color Palette:
- High contrast neon/tech on dark: Electric blue, neon green, safety red, and muted amber.
- Low-saturation muted gray/white text for secondary data.


# Animation:S

- Functional 2D vector translations. Smooth linear or ease-in-out transitions for lines drawing, counters ticking, or simple curves forming. Maintain a clean, professional, and educational aesthetic.

# Content
## For portrait aspect ratio like 9:16, 3:4 etc.: 
* Top 10% and bottom 20% shouldn't have any content to keep in the social media safezone. Subtitle should be placed between 75%-80% region from the top.
* But you can make repeating background structure take out the whole screen. 



# Subtitle:
Each subtitle chunk should be at max 7-8 words long and synchronized to narration audio.
