# Teach with examples, and teach step by step.
## Don't
```
Topic: What is a fraction?

A fraction is a number that represents a part of a whole. It consists of a numerator and a denominator. The numerator indicates how many parts are being considered, and the denominator indicates the total number of equal parts.
```

## Do
```
Topic: What is a fraction?

A fraction is a number that represents a part of a whole. It consists of a numerator and a denominator.

Example: Imagine a pizza cut into 8 equal slices. If you eat 3 slices, you have eaten 3/8 of the pizza.

3 (numerator) = slices eaten
8 (denominator) = total slices

So, 3/8 means "3 out of 8 equal parts."
```
