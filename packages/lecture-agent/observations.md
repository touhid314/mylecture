- The LLM can generate long htmls covering 2 minutes or even larger, but the longer the generation the less reliable the generation is, more error prone it is. 30s-60s generation are the best length so far. maybe 15-20s is better for animation heavy situations.
- The main reason for overflow is usually text, and that's because in the contract we have said not to use CSS animation, but the LLM is misinterpreting this. It's not using any HTML for actually text-based things, so as a result it is using canvas for text-based things. In canvas there are no inherent repping mechanisms, so that's why the LLM has no sense of whether the text is overflowing in the background that it has created behind, because canvas is just raw drawing.
